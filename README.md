# PhotoLab EDGE Companion

The free Windows program behind the **PhotoLabEdge** iCUE widget for the Corsair XENEON EDGE. The widget (sold on the Elgato Marketplace) can only carry web files, so the part that talks to DxO PhotoLab is this program. It runs on your own PC and answers the widget on `127.0.0.1:47620`. No internet, no account, no telemetry.

**Download and setup guide:** https://pathfinderprototyping.com/support/photolab-edge/

This repository holds the releases only. Each release carries `PhotoLabEdgeCompanion.exe` and its SHA-256. Double-click the exe once: it installs itself under your local AppData `Programs\PhotoLabEdge` folder, registers a sign-in task so it starts with every sign-in, and lists itself under Settings, Apps for removal.
